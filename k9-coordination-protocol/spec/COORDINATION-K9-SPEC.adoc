invariants
Rules that MUST NOT be violated. Each invariant has an id, rule, and reason.

invariants:

    rule: "Do not introduce TypeScript files anywhere in this project"
    reason: "ReScript is the chosen frontend language — this is deliberate"

Validation Rules
File MUST start with K9! on line 1

metadata section MUST be present with schema: k9-coordination

project section MUST be present

invariants section MUST be present (even if empty list)

Each invariant MUST have id, rule, and reason

Each protected entry MUST have path and reason

Severity defaults to critical if omitted

Generator Behaviour
The generator reads coordination.k9 and emits one file per supported AI tool. All generated files:

Start with a comment indicating they were generated from coordination.k9

Include a "do not edit directly" warning

Render all sections as markdown appropriate for the target tool

Are idempotent — re-running overwrites with current state

Generated files SHOULD be committed to the repository so that AI tools which read them on startup get the coordination context immediately.

Relationship to Existing Files
coordination.k9 does NOT replace:

0-AI-MANIFEST.a2ml — the gateway file still serves as universal entry point

.machine_readable/*.a2ml — state/meta files remain authoritative

.claude/CLAUDE.md — can coexist; generated CLAUDE.md merges with existing

The A2ML gateway SHOULD reference coordination.k9 in its inventory so agents following the gatekeeper protocol discover it.
