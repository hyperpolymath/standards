== rhodium-minimal - Technical Overview

*Minimal Rhodium Standard Repository (RSR) Compliant Example*

'''''

=== 🎯 Design Goals

This minimal example demonstrates RSR compliance with:

[arabic]
. *Simplicity*: ~100 lines of Rust code
. *Self-Contained*: Zero dependencies
. *Type Safety*: Rust compile-time guarantees
. *Memory Safety*: Ownership model
. *Offline-First*: No network calls
. *Complete Documentation*: All required RSR files
. *Bronze Compliance*: 75-89% RSR compliance

'''''

=== 🔧 Implementation Details

==== Type Safety (Rust)

[source,rust]
----
// Compile-time verification:
// - No null pointer dereferences (Option<T>)
// - No buffer overflows (bounds checking)
// - No use-after-free (ownership model)
// - No data races (borrow checker)

fn main() -> Result<(), io::Error> {
    // Return type ensures proper error handling
    check_compliance()?;
    Ok(())
}
----

==== Memory Safety

* *Ownership Model*: Single owner, borrowing rules enforced at
compile-time
* *No Garbage Collection*: Deterministic resource cleanup
* *Zero Unsafe Code*: `+just check-unsafe+` verifies

==== Offline-First

[source,rust]
----
// Zero network dependencies in Cargo.toml:
[dependencies]
# (empty - demonstrates offline-first principle)
----

All functionality is self-contained: - No HTTP requests - No DNS lookups
- No socket connections - Works in air-gapped environments

==== SPDX Headers

Every file has:

[source,rust]
----
// SPDX-License-Identifier: MPL-2.0
// SPDX-FileCopyrightText: 2025 The Rhodium Standard Contributors
----

Verified with: `+just audit-licence+`

=== 🔄 Build Process

==== Using Just (Recommended)

[source,bash]
----
# View all commands
just --list

# Build
just build

# Run
just run

# Test
just test

# Full validation
just validate
----

==== Using Cargo Directly

[source,bash]
----
# Build
cargo build --release

# Run
cargo run --release

# Test
cargo test
----

==== Using Nix (Reproducible)

[source,bash]
----
# Enter development shell
nix develop

# Build
nix build

# Run
./result/bin/rhodium-minimal
----
