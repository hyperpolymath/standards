== Ruby → Rust Migration Guide

=== Policy

Ruby code should be migrated to Rust for: - Better memory safety -
Performance improvements - Static typing

=== Migration Steps

[arabic]
. Create `+Cargo.toml+` and `+src/main.rs+`
. Convert Ruby classes to Rust structs
. Use `+serde+` for serialization
. Remove Gemfile and *.rb files after migration
