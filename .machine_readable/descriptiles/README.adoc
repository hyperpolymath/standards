= Descriptiles
:revdate: 2026-10-24

Deeds whose names are all capitals live here.

`0-AI-MANIFEST.deed` is here because the name `AI-MANIFEST` is all capitals.
The `0-` prefix is the ply number, not a letter. It is still the agent front
door. Humans start at `README.adoc`, which stays at the repository root, as
does `EXPLAINME.adoc`.

`standards_chora.deed` stays at the repository root. Its name is lowercase,
and the required-files rule says the chora deed is a root file. Praxis deeds
stay beside the specification they describe. Grammar fixtures under
`1-formats/deed/tools/fixtures/` are tests, not repository deeds, and stay there.

A deed whose name starts with a capital letter, and is not all capitals,
belongs in `.machine_readable/contractiles/`, not here. None is in the tree yet.

The old all-capitals `.a2ml` records are not live. They are under
`9-archive/a2ml/.machine_readable/descriptiles/`. Their present-tense
fields were rewritten as clauses of `standards_chora.deed`. Do not add a
new `.a2ml` file here.
