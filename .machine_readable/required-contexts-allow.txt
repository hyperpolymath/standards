# known to be unsatisfiable on a pull request.

# Every line is a debt with a name and a reason: `context`
#
# WHY THIS FILE EXISTS INSTEAD OF `continue-on-error: true`
# ---------------------------------------------------------
# The alternative was an always-green advisory job, and this repository has
# already paid for that: a gate that reports the same colour on every pull
# request is indistinguishable from a gate that is satisfied. (It is also how
# `scripts/check-required-contexts.sh` itself went unnoticed for a month — it
# was never wired, so it never disagreed with anything.)
#
# So the job FAILS on any unsatisfiable required context that is not listed
# here, and passes only for the ones below, which are reported on every run.
# A new entry cannot be added quietly: this file is the review surface.
#
# Removing the last entry is the point, not an edge case.
#
# The known entry is a branch RULE, not a missing workflow. The scan it names
# does run on every pull request — as `Hypatia verdict grid / Hypatia
# Neurosymbolic Analysis`, the fork-governance lane. The required context names
# the OTHER call site of the same reusable workflow: hypatia-scan.yml, whose
# `scan` job is deliberately push/schedule-only so the same findings are not
# uploaded to code scanning twice per pull request. So the defect is a context
# name pointing at the post-merge call site of a scan that is gated pre-merge
# under a different name.
#
# Consequence, measured on #1336: 65 checks green, reviewDecision clear,
# mergeable, and still BLOCKED — because the required check can never appear.
# Every pull request in this repository is in that state, and the only way work
# lands is the ruleset's `always` bypass, which discards the other nineteen
# required checks in the same action. That is the whole failure mode this
# repository keeps re-learning: the bypass is not an escape hatch used
# occasionally, it is the actual merge path, and it makes the nineteen
# decorative.
#
# Repair (decision layer, needs repository admin — the ruleset, not this file):
# replace the context below with `Hypatia verdict grid / Hypatia Neurosymbolic
# Analysis` in ruleset 23787415, leaving the other nineteen untouched.
#
# Format: one context per line; `#` starts a comment; blank lines ignored.
