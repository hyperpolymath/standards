= K9-SVC starter templates

Three starting points, one per trust level:

* `level1-data.k9.ncl` — pure data, no execution, safe in all environments.
* `level2-validated.k9.ncl` — Nickel contract evaluation permitted.
* `level3-signed.k9.ncl` — full execution; the `signature` field is a
  placeholder — generate a real one with your toolchain before use.

Copy whichever matches the trust you need — the environment grants no more
than the component declares. See https://k9-svc.net/start.html[Get started]
and https://k9-svc.net/spec.html[the specification]. Templates are
`MPL-2.0`; this note is `CC-BY-SA-4.0`.
