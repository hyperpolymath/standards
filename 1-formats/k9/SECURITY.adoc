=== Reporting a Vulnerability

If you discover a security vulnerability in K9 SVC, please report it by:

[arabic]
. *DO NOT* create a public GitHub issue
. Email security concerns to the maintainer privately
. Include a detailed description of the vulnerability
. Provide steps to reproduce if possible

=== Security Model

K9 implements a tiered security model called "`The Leash`":

* *Kennel*: Pure data, no execution
* *Yard*: Nickel validation only, no I/O
* *Hunt*: Full execution, requires cryptographic handshake

For details, see link:SPEC.adoc#security-model[SPEC.adoc].

=== Security Considerations

Since K9 files can contain executable logic:

[arabic]
. Never run `+'Hunt+` level components from untrusted sources
. Always validate components in `+'Yard+` mode first
. Review Just recipes before granting execution permission
. Use the cryptographic handshake for production deployments
