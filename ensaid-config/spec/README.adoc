== Overview

This directory contains the formal specification for the `.ensaid-config/`
directory standard -- per-repository configuration for eNSAID-compatible
development environments (PanLL and beyond).

== Document Index

=== Core Specification

link:ENSAID-CONFIG-SPEC.adoc[ENSAID-CONFIG-SPEC.adoc]::
  The complete specification in RFC-style format. Defines the directory
  structure, file formats, discovery rules, versioning policy, and
  relationship to other hyperpolymath standards.

== Using This Specification

=== For Tool Implementers

1. Read the link:ENSAID-CONFIG-SPEC.adoc[full specification]
2. Implement discovery (find `.ensaid-config/` at repo root or parent dirs)
3. Parse A2ML files using a TOML-compatible parser
4. Apply settings with correct precedence (repo overrides user-level defaults)

=== For Repository Authors

1. Create `.ensaid-config/` at your repository root
2. Add only the files you need (all are optional)
3. See the specification for the schema of each file
