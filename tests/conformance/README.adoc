= Conformance evidence

The runner writes `YYYY-MM-DD/pr-N/run-ID-ATTEMPT/` here, in UTC. Each directory
contains `report.json`, the compact `report.md`, raw category logs and the
validator's `corpus.jsonl`. Git ignores generated date directories. CI uploads
each directory as a named artifact retained for 90 days; the PR report links to
the run. Download it for longer retention. CI does not commit generated logs
back to contributor branches.

The schema, meaning of colours, comparison rules and reproduction commands are
documented in link:../../1-formats/k9/tools/CONFORMANCE-REPORTING.adoc[the reporting guide].
