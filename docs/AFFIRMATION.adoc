== We affirm

Binding now. Each item is checkable against the anchor below.

. *The canon's law is hash-pinned.* `canon.lock` records a `sha256` for the
  criteria, the gate table, the applicability policy, the lifecycle spec and
  the constitution. `scripts/check-canon-lockstep.sh` verifies all five against
  the working tree.
. *The canon is subject to its own law.* `.machine_readable/rsr-profile.a2ml`
  declares `role = "canon"` and an honest capability set;
  `scripts/check-rsr-profile.sh .` runs against this repository. Before this
  existed, that script exited `2` on the repository that ships it.
. *The repository is mapped.* `standards-map.toml` carries one record per
  top-level entry, and `scripts/check-standards-map.sh` checks it
  **bidirectionally** — an unlisted entry fails, and a listed entry whose path
  is gone also fails.
. *A canon change cannot be silent.* Any commit touching a file named in
  `canon.lock [canon.artifacts]` without bumping `[canon].version` and its hash
  fails Gate A assertion 2.
. *Licence and SPDX are manual-only.* No agent has edited, swept or relicensed
  `LICENSE` or any SPDX header in this repository.
. *Ruling R-A is settled: the machine tree is `.machine_readable/`.* The
  hyphenated `machine-readable/` spelling is the minority form, not an
  alternative canonical one, so this repository does not migrate. The census in
  rsr-template-repo's `docs/governance/TEMPLATE-LINEAGE-AUDIT.adoc` — **48
  repositories dotted against 9 hyphenated** at the 2026-08 divergence — shows
  the spine's 2026-08 un-hiding was the minority position. This confirms Ruling
  10 of `STANDARDS-CRITICAL-PATH.adoc`. Both spellings still *resolve* in every
  shared tool; neither is rejected.
