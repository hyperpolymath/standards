= standards — Quick Start for Consumers
:toc:

[NOTE]
This is a *specs* monorepo, not an application to install and run. "Using" it
means *applying* the standards to your own repository. The canonical front door
is link:../../README.adoc[README.adoc].

== What is standards?

The organization-wide source of truth for Hyperpolymath policies, the deed
and K9 foundation, the protocols, the readiness-grading frameworks
(ARG/FRG/CRG/TRG under `4-readiness/`), RSR compliance, and the enforcement/CI
that makes them stick. See link:../../README.adoc[README.adoc] for the full overview and the
"if you want X, go here" routing table.

== Apply the standards to your repo

[source,bash]
----
git clone https://github.com/hyperpolymath/standards.git
----

. *Scaffold a compliant repo:* follow the *Usage* section of link:../../README.adoc[README.adoc]
  and link:../../.meta/REQUIRED-FILES.adoc[.meta/REQUIRED-FILES.adoc].
  Do not create `.a2ml` files; A2ML is retired.
. *Adopt enforcement:* copy the relevant link:../../.github/workflows/[workflows] and
  link:../../hooks/[hooks].
. *Follow the language + licence policy:* link:../../.claude/CLAUDE.md[.claude/CLAUDE.md].
