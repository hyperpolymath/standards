Audience quickstarts and paste-in warm-ups. These are thin pointers, not
front doors.

* Humans start at link:../../README.adoc[README.adoc].
* Agents start at link:../../.machine_readable/descriptiles/0-AI-MANIFEST.deed[0-AI-MANIFEST.deed], then
  link:../../standards_chora.deed[standards_chora.deed] for repository facts.

The provisioning standard allows warm-ups at the root or in
`docs/onboarding/`. This repository keeps them here, so the root stays
limited to files a tool, a forge, or the spine reads in place.
