=== B. Failed or cancelled on main: root causes

==== 1. README Derive: this repo's bug (has never succeeded in 36 runs)
* Run 38482953895 on 48e0ed9 ended in `failure` with *0 jobs* after 1 s. `gh run view` shows only "This run likely failed because of a workflow file issue".
* Cause: a concurrency deadlock.
** `readme-derive.yml` (the caller) and `readme-derive-reusable.yml` both declare a workflow-level `concurrency: group: ${{ github.workflow }}-${{ github.ref }}`.
** Inside a called workflow, `github.workflow` evaluates to the *caller's* name. Both groups therefore resolve to `README Derive-refs/heads/main`.
** GitHub detects the self-deadlock and kills the run before it creates any job.
* Evidence:
** It is the *only* caller/reusable pair in the repo with workflow-level concurrency on both sides. elixir-ci, scorecard, secret-scanner and codeql have it on the caller only, and they run.
** The caller was created on 2026-07-28 with the colliding block (be51a134, "Generated by Mistral Vibe").
** Every run since then: 8 `startup_failure`, early ones from a permissions mismatch fixed by #652, then 28 `failure` with jobs=0.
* Fix: delete the `concurrency:` block from the reusable. A reusable should never key on `github.workflow`.
* Even fixed, it does nothing in standards. The repo has no `[publishing.readme]`, and the reusable reads the retired `ECOSYSTEM.a2ml`.
