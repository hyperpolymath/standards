== Session mechanics for this wave

* *Executor:* this session, switched to the sonnet tier. Effort *medium*
  for WO-1, WO-3, WO-6 and WO-8; *high* for WO-2, WO-4, WO-5 and WO-7,
  which edit validators, CI or many files.
* *One order, one branch, one PR.* Branch `tidy/wo-N-<slug>` from the
  current `origin/main`. Never reuse a merged branch. The owner has to
  grant this session permission to push to `tidy/*` branches once; until
  then the executor stops before the first push and says so.
* *Never:* merge, force-push, admin-override, touch a licence file or
  header, edit `9-archive/` content or `3-practice/outreach/`, create or
  extend a `.a2ml`, edit a descriptile by hand (D313), or sweep.
* *Before every push, all of:* `bash scripts/check-standards-map.sh`,
  `bash scripts/check-canon-lockstep.sh`,
  `bash scripts/run-mustfile.sh .machine_readable/contractiles/must/Mustfile.a2ml`,
  `bash scripts/run-debtfile.sh .machine_readable/Debtfile.a2ml`,
  `bash scripts/link-rot-guard.sh <dir you touched>`,
  `bash scripts/check-canonical-names.sh origin/main`,
  `bash scripts/check-launcher-standard-currency.sh --root .`,
  `git diff --check`, plus the order's own acceptance block. The
  repo-wide link-rot guard reports two broken issue-template links that
  predate this work (#830); they are not yours.
* *PR body:* the order id, the authority line per change, the acceptance
  block with every result pasted verbatim, a "not done" list. Open as a
  draft; mark ready when the acceptance block is green; watch CI; fix
  reds; stop at merge.
* *Stop and ask* whenever an order's _Escalate if_ condition is met. A
  stop is a one-paragraph message naming the order, the condition, both
  arms with the elegant one first, and what you did meanwhile.
* *Order and concurrency* (at most three PRs open at once):
  WO-1 first; then WO-2, WO-3 and WO-8 in parallel; then WO-4, WO-5 and
  WO-6 strictly in that sequence (all three edit `.hypatia-baseline.json`);
  WO-7 may run beside WO-4. P1.2, P1.3, P1.6 and P1.9 are not in this
  wave: they wait on the owner items at the end.

*Acceptance.*
