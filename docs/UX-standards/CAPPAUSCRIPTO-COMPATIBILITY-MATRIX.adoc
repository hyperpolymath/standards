== Scope

This matrix tracks CoffeeScript-idiom compatibility for CappauScripto.

Related documents:

* link:CAPPAUSCRIPTO-FACE-IDENTITY-CARD.adoc[Face Identity Card]
* link:CAPPAUSCRIPTO-RELEASE-GATE-TRACKER.adoc[Release Gate Tracker]
* link:CAPPAUSCRIPTO-MIGRATION-SPEC.adoc[Migration Spec]

Important:

* This document is a target matrix until runtime evidence links are attached.
* Status MUST move from target to measured before a launch claim.

== Status Legend

* `V1-Required`: must be fully supported for first public launch.
* `V1-Partial`: acceptable for launch with documented caveats.
* `V2-Deferred`: intentionally postponed.
* `Blocked`: cannot proceed without core changes or design decision.

== Known Caveats (Must Be Visible)

[cols="1,3,2", options="header"]
|===
| ID | Caveat | Mitigation

| CV-01
| Optional-call syntax can create parse ambiguities in dense chained calls.
| Prefer explicit parentheses where ambiguity is detected; autofix in `cappa migrate`.

| CV-02
| `unless` readability may degrade with nested boolean expressions.
| Lint recommendation to rewrite to `if not` for complex predicates.

| CV-03
| Comprehension side effects can hide ordering bugs in migrated code.
| Migration tool emits warning and suggests explicit `map`/`filter` rewrite.
|===

== Launch Exit Criteria

Compatibility can be declared launch-ready only when:

* all `V1-Required` rows have evidence links and passing results,
* no `Blocked` row is unresolved,
* caveats are mirrored in migration diagnostics and docs.
