= Standards PanLL Panels — Skeleton Components
:status: Draft

ReScript panel skeletons for the three standards-repo PanLL panels
defined in `docs/PANLL-PANELS.adoc`.

== Files

| File | Purpose |
|---|---|
| `manifest.json` | PanLL panel manifest (3 panels) |
| `src/VcldbClient.res` | VeriSimDB query client + typed helpers |
| `src/CrgDashboard.res` | Grade distribution panel |
| `src/ComplianceMonitor.res` | Findings heatmap panel |
| `src/ProofHub.res` | Proof table panel |

== Status

Skeleton only. These components:

- Fetch data via `VcldbClient` (hits port 8097, the standards VeriSimDB instance)
- Render minimal HTML tables / cells
- Auto-refresh on the interval declared in `manifest.json`

They do NOT yet:

- Render charts (distribution pie, axiom bar chart)
- Handle drill-down interactions
- Integrate with PanLL's layout/workspace system
- Have tests

== Next steps

1. Fold into the PanLL repo's `src/panels/standards-*/` tree
2. Replace raw HTML with PanLL's `@panll/ui` components
3. Add Tea wiring for panel-to-panel messaging
4. Write integration tests against a mock VeriSimDB

== Dependencies (when wired in)

- `@rescript/react` for JSX
- VeriSimDB running at `http://localhost:8097` (standards instance)
- PanLL workspace manifest must include `panll-panels/manifest.json`
