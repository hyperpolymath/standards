= Required Repository Files

The following files *MUST* be present and kept up-to-date in every repository:

== Mandatory Dotfiles

[cols="2,3"]
|===
| File | Purpose

| `.gitignore` | Exclude build artifacts, secrets, and temp files
| `.gitattributes` | Enforce LF line endings and diff settings
| `.editorconfig` | Consistent editor settings across IDEs
| `.tool-versions` | asdf version pinning for reproducible builds
|===

== Machine-Readable Metadata

[IMPORTANT]
====
*A2ML is retired* (owner rulings D99, D269c, D312, D313). This section used to
require six `.a2ml` files (META, STATE, ECOSYSTEM, PLAYBOOK, AGENTIC,
NEUROSYM). Do not create them, restore them, or write a "new" A2ML file in
their place. Their content now lives in deed clauses, as below. `.scm` stays
reserved for Guix files (`guix.scm`, `.guix-channel`).
====

[cols="2,3,3"]
|===
| File | Purpose | Grammar and check

| `<repo>_chora.deed` (repo root, one per repo)
| The repo's facts: identity, state, meta, ecosystem, agentic, neurosym,
  playbook, and the `(bot-directives …)` and `(contractiles …)` clauses (D312).
| link:../1-formats/deed/spec/abnf/deed.abnf[`deed.abnf`] (normative, D308).
  Check with `bun 1-formats/deed/tools/deed_lint.js FILE.deed`. Model:
  `rsr-template-repo_chora.deed` in `hyperpolymath/rsr-template-repo`.

| `*.k9.ncl`
| Contracts. The chora deed attests to them through its `(contractiles …)` clause.
| link:../1-formats/k9/spec/K9-CONTRACT-SPEC.adoc[K9 contract spec]. Check with
  `1-formats/k9/tools/k9-validate.sh --strict FILE`.

| `coordination.k9` (repo root)
| Agent coordination rules. First line `K9!`, `schema_version: 1.1.1`.
| link:../2-protocols/k9-coordination/spec/abnf/coordination-k9-grammar_v1.1.abnf[`coordination-k9-grammar_v1.1.abnf`]
  (prose: link:../2-protocols/k9-coordination/spec/COORDINATION-K9-SPEC.adoc[COORDINATION-K9-SPEC]).
  No validator script exists yet, and a generic YAML parser does not conform.
|===

Where a former A2ML record's content goes is decided by the mapping specs in
link:../1-formats/deed/mappings/[`1-formats/deed/mappings/`]. Anything a
mapping spec does not list does not translate.

== Build System

[cols="2,3"]
|===
| File | Purpose

| `justfile` | Task runner (replaces Makefile)
| `Mustfile` | Deployment state contract
|===

*IMPORTANT*: Makefiles are FORBIDDEN. Use `just` for all tasks.

== Validation

These files are checked by:

* CI workflow validation
* Pre-commit hooks (when configured)
* Repository standardization scripts

== Updates

When updating these files:

. Use templates from `rsr-template-repo` as reference
. Ensure SPDX license header is present
. Test changes locally before pushing
. Keep language-specific sections relevant to the repo
