= A2ML archive
:toc:
:icons: font
:revdate: 2026-10-24

WARNING: A2ML is retired. This directory is the reserved shelf for it.
Nothing here is a live standard. Do not copy a file out of here into
`1-formats/`, `.machine_readable/`, `hypatia-rules/`, or the repository
root. Do not add a new `.a2ml` file anywhere outside `9-archive/`.

The guard is `scripts/check-a2ml-archived.sh`. It fails if a tracked
`.a2ml` or `.a2ml.template` exists outside `9-archive/`.

== What was put here

Live A2ML was moved on 2026-10-24. The original path is preserved under
this directory, so a reader can see where a file used to sit.

* `1-formats/a2ml/` — the format specification and its examples
* `1-formats/templates/` — the templates and the migration scripts
* `1-formats/A2ML-REPO-TEMPLATE.adoc` and `1-formats/SATELLITES.a2ml`
* `.machine_readable/` descriptiles, contractiles, scorecards, and the debt and claims ledgers
* `hypatia-rules/*.a2ml`
* `0-canon/rsr/rsr-criteria-v2.a2ml` — still hash-pinned by `canon.lock`. The bytes did not change, so the canon version was not bumped.
* `hooks/playbook-to-recipe/` and `tools/scm-to-a2ml-bot-directives/`

== What was left where it was

Files already inside another `9-archive/` last-copy stay in that last-copy.
Moving them would falsify the frozen tree. They are already not live
standards. The guard allows any `.a2ml` under `9-archive/`.

== Readers

Nothing live should open a file here as a current standard. The records
that were still executed were rewritten as deeds (`must_praxis.deed`,
`debt_praxis.deed`, `claims_praxis.deed`, `rsr-criteria-v2_praxis.deed`,
and the Hypatia `*_praxis.deed` files). Scripts that other repositories
call against their own `.machine_readable/Debtfile.a2ml` still accept that
caller path. Pass an explicit path to measure a different file.

Do not edit a body in this shelf to satisfy a gate. A hash-pinned file
(`canon.lock` criteria) must stay byte-identical unless the canon version
is bumped in the same commit.
