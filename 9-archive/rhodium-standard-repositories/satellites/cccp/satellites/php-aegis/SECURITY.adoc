=== Reporting a Vulnerability

If you discover a security vulnerability in php-aegis, please report it
responsibly.

==== Process

[arabic]
. *Do not* open a public GitHub issue
. Report via
https://github.com/hyperpolymath/php-aegis/security/advisories/new[GitHub
Security Advisories] (preferred)
. Or contact the maintainer via https://github.com/hyperpolymath[GitHub
profile]

==== Include

* Description of the vulnerability
* Steps to reproduce
* Potential impact assessment
* Suggested fix (if any)

==== Timeline

* Acknowledgment within 48 hours
* Status update within 7 days
* Credit in security advisory (unless you prefer anonymity)
* 90-day disclosure window

=== Security Design Principles

php-aegis is built with these principles:

* *Defense in Depth*: Multiple layers of validation
* *Fail Secure*: Errors deny access rather than grant it
* *Least Privilege*: Methods do minimum necessary
* *Input Validation*: All input treated as untrusted
