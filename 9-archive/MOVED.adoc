== Left at the root on purpose

These are not leftover. A later cleanup should not move them without a
consumer that has stopped reading the path.

* Front door and forge files: `README.adoc`, `EXPLAINME.adoc`, `AGENTS.adoc`, `CHANGELOG.adoc`, `ROADMAP.adoc`, `READINESS.md`, `SECURITY.md`, `REGISTRY.adoc` (ruled redirect; the registry was retired 2026-10-09, and the six-month stay has not elapsed).
* Spine and licence: `LICENSE`, `NOTICE`, `PALIMPSEST.adoc`, `LICENSES/`. `licenses/` (lowercase translations) stays until the owner routes it; it case-collides with `LICENSES/` and was not touched.
* Machine entry the grammar requires at the root: `standards_chora.deed` (lowercase; required-files D312), `coordination.k9`, `canon.lock`, `standards-map.toml`. `0-AI-MANIFEST.deed` left the root later the same day; see below.
* Tools that read a fixed root path: `Justfile`, `guix.scm`, `setup.sh` (the published raw URL is the root), `.gitignore`, `.gitattributes`, `.editorconfig`, `.gitleaks.toml`, `.gitleaksignore`, `.governance-allowlist`, `.hypatia-baseline.json`. `CLAIMS.a2ml` left the root later the same day.
* Forge and agent conventions: `.github/`, `.githooks/`, `.claude/`, `.devcontainer/`, `.machine_readable/`, `.meta/`, `www/`, `docs/`.
* Machinery whose current path is a published or workflow-relative contract: `scripts/`, `hooks/`, `config/`, `tools/`, `tests/`, `templates/`, `hypatia-rules/`, `launcher/`. The map's `5-machine/` target is not applied here. The launcher resolution ladder still names its current path, and reusable workflows call `bash scripts/…` from the checkout root. The `.a2ml` files that were in `hypatia-rules/` later moved to the A2ML shelf; the directory itself stays so the RuleLoader path is an empty, explained shelf rather than a missing directory.
* `rhodium-standard-repositories/` remains a residual published allowlist URL. Moving it breaks raw fetches outside this repository.
* `.verisimdb/` and `.hypatia/` stay. The map's `6-telemetry/` and `5-machine/` targets are not applied: the baseline scanner and the local VeriSimDB config still expect those paths, and `.hypatia-baseline.json` must stay at the root because the scanner reads it there.
* Districts already in place: `0-canon/`, `1-formats/`, `2-protocols/`, `3-practice/`, `9-archive/`, and now `4-readiness/`.

== A2ML shelf and deed placement (2026-10-24)

A2ML is retired. The reserved shelf is `9-archive/a2ml/`. Every tracked
`.a2ml` that was not already under `9-archive/` was moved there, original
path preserved. The format tree `1-formats/a2ml/`, the templates, the
repository template, `hooks/playbook-to-recipe/`, and
`tools/scm-to-a2ml-bot-directives/` went with them. Frozen last-copies
already inside `9-archive/` were not opened.

`README.adoc` and `EXPLAINME.adoc` stay at the root. The all-capitals deed
`0-AI-MANIFEST.deed` moved to `.machine_readable/descriptiles/` (the ruled
spelling; an undotted `machine_readable/` was not created). No deed starts
with a capital letter that is not all capitals, so
`.machine_readable/contractiles/` received no deed. `standards_chora.deed`
stays at the root: lowercase, and required there. Praxis deeds stay with
their specifications. Grammar fixtures were not moved.

`canon.lock` records the criteria file at its new path. The hash is
unchanged, so the canon version was not bumped. This repository's Mustfile,
debt, claims, and contractile-index readers were pointed at the shelf so
those gates do not go false-green. Scripts that other repositories call
against their own `.machine_readable/Debtfile.a2ml` still default to that
caller path.

`3-practice/outreach/` prose was not rewritten (D278b). Its six `.a2ml`
files were moved with the rest.

The same day, the A2ML that was still executed was rewritten in the deed
grammar, not renamed. Live files: `standards_chora.deed` (descriptile
clauses), `.machine_readable/contractiles/must/must_praxis.deed`,
`.machine_readable/debt_praxis.deed`, `.machine_readable/claims_praxis.deed`,
`0-canon/rsr/rsr-criteria-v2_praxis.deed`, and `hypatia-rules/*_praxis.deed`.
Contractile declarations point at the existing `*.k9.ncl` files.
`coordination.k9` was already the coordination format and was not an A2ML
file. `canon.lock` is 2.1.3: the criteria hash changed because the format
changed; the 78 criteria were not.
